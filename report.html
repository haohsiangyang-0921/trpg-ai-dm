🎲 單人 TRPG 故事生成與 AI 裁判系統

基於 Streamlit 與本地大型語言模型（Local LLM）的智能文字冒險應用
專案負責人：haohsiangyang-0921
開發技術：Python, Streamlit, Ollama, REST API
報告日期：2026 年 11 月

一、做什麼（What & Why）：專題背景與核心機制

傳統桌上角色扮演遊戲（TRPG）以高自由度與沉浸劇情著稱，但通常面臨**「開團門檻高、組隊不易、缺乏資深地下城主（DM）」**等痛點。本專題旨在打造一款單人隨開即玩的 TRPG 智能冒險平台，將現代大語言模型（LLM）賦予為經驗豐富且風趣嚴謹的 AI 裁判。

🌟 三大核心特色：
  1. AI 數值與命運判定：AI 自動進行暗骰（d20）檢定，即時計算戰鬥傷害（扣除 HP）、探索補給、道具掉落與地點轉移。
  2. 動態三風格建議行動：每回合自動生成「🅰️ 常規穩健」、「🅱️ 策略洞察」、「🅲 搞笑奇策」三種按鈕，兼顧自由度與輕鬆操作，並保留自由打字框。
  3. 隱私優先與本地運行：全面適配本機運行之 Ollama 與 LM Studio，資料免上傳雲端、無 API 呼叫費用限制。

三、怎麼做（Architecture & Implementation）：架構與技術實作

系統採用極簡單一檔案（Single-file Architecture）架構設計，有效將系統相依性降到最低：

  • 前端展示層（Streamlit）：透過 st.session_state 維護玩家血量、道具清單與對話歷程；採用 st.columns 渲染動態選項按鈕，並配合自訂 CSS 標籤展示生命與道具變動。
  • 無依賴通訊層（Zero-dependency HTTP）：捨棄肥大的第三方套件，以標準 requests 模組直接發送符合 OpenAI 規範的 RESTful API 請求，完全解耦外部套件依賴。
  • 提示詞工程與結構化契約（System Prompt & JSON）：約束 AI 僅輸出標準 JSON 格式（含 story, hp_change, items_obtained, location, options），並實作正規表示式正則抽取，杜絕模型雜訊解析失敗。
  • 三層容錯防禦體系：包含側邊欄即時連線健康檢查燈號（🟢/🔴）、連線異常自動重試面板、及內建免模型即可體驗的「🎭 離線模擬模式」。
